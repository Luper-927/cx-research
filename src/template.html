Project / Identity

About CX

Project CX is being developed as foundational infrastructure for interactions among independently operated autonomous systems.

Current interface boundary

This deliverable implements the presentation layer only: page structure, responsive styling, navigation between interface sections, theme preference, keyboard-accessible command palette and notifications.

It does not implement identity, authority, resource control, inter-system interaction, cryptographic verification, persistence, journal semantics or recovery. Those must come from separately tested engine components.
